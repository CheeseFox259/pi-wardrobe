# Portable preset sources and shared authoring drafts

The confirmed October 2026 redesign makes all presets, including the first captured global environment, ordinary entries in a searchable roster. Creation, import, editing, maintenance and sharing are general operations. Perfect Pi has no dedicated migration action. The recovery backup stays separate from editable preset source.

Manual editing and Pi-assisted authoring operate on the same standalone public source draft. Review captures an immutable Git snapshot through the existing plan/install protocol. Saving retains older revisions and changes neither the running environment nor startup defaults; selecting a saved revision starts a new conversation through the existing clean process handoff. Pi-assisted creation uses the native current model in a separate conversation and returns a draft for review.

Copies receive independent identities. Edits of locally authored presets retain identity and produce new versions; edits of upstream presets record local derivation. The roster groups revisions by identity, while historical conversation bindings address exact revisions. Each user's original environment gets an independent identity.

Public resources and companions are bundled in portable source. A source can declare device requirements for private configuration, tools or local resources; only the requirement travels. Values live privately under the device's native Wardrobe store. Required missing bindings prevent activation. Native models, authentication and project configuration remain owned by Pi.

Local import accepts standard preset directories and indexed collections, or normalizes an ordinary Pi configuration directory. Export writes a standard public directory, without publishing. Common credential files, live links, embedded secrets and user paths are excluded or refused, and custom contents still require review. Disabled public resources remain available through the source's resource catalog without being activated.

The UI uses short action names and progressively opened management menus. Pi and extension updates remain native `pi update`; Wardrobe maintains preset and upstream skill lineage in separate workspaces. Ordinary startup performs no authoring or maintenance scan.
