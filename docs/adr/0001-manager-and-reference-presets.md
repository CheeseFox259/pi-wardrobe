# Keep the manager independent of its reference presets

Pi Wardrobe is the general preset manager; Perfect Pi is an optional reference preset using the same public declaration and adapter contracts as community presets. We reject embedding the existing Perfect Pi distribution as mandatory manager behavior, because that would couple engineering workflows and private configuration to every user. This separation requires demonstrating the public contract with an independent preset as well as Perfect Pi; missing migration capabilities remain explicit gaps, not privileged paths.
