# pi-wardrobe

Reproducible preset lifecycle for Pi. The approved V1 specification is in
[`docs/specs/wardrobe-v1.md`](docs/specs/wardrobe-v1.md), mirrored by
[issue #8](https://github.com/CheeseFox259/pi-wardrobe/issues/8), which remains
authoritative.

Implementation is under way. The controlled native fixtures that the
implementation tickets build on are documented in
[`fixtures/README.md`](fixtures/README.md); run them with:

```sh
npm run fixtures:verify
```

Shared language is in [`CONTEXT.md`](CONTEXT.md) and architecture decisions in
`docs/adr/`.
