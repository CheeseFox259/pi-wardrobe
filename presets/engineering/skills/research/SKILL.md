# Research

Investigate complex architectural, algorithmic, or library questions against primary sources, producing factual, verified findings.

## Prerequisites

- Read access to project source trees, local dependency definitions, and documentation.
- If external web search or network fetch tools are required but not active in this preset:
  - Report online research tools as **UNAVAILABLE**.
  - Confine investigation to local documentation, installed types, package manifests, and repository notes.
  - Never fabricate external documentation or claim web search occurred when offline.

## Process

1. **Clarify Research Objective**:
   Define the exact architectural question, trade-offs, or constraints to investigate.
2. **Consult Primary Sources**:
   Examine local source code, upstream type declarations, ADRs, and official specifications.
3. **Capture Findings**:
   Write concise, verifiable findings with source citations and save them in `docs/research/` or the relevant planning folder.
