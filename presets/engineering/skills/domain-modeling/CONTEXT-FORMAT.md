# Context Map and Domain Glossary Format

`CONTEXT.md` serves as the authoritative ubiquitous language dictionary for the project.

## Structure

1. **Mission**: A 1-2 sentence core purpose statement for the system or module.
2. **Ubiquitous Language**: Table or glossary of exact terms, their definitions, and non-examples.
3. **Boundaries**: Subsystems, inbound/outbound dependencies, and integration seams.
